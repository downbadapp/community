# DownBad Community

The place for bugs, feature requests, and general discussion.

## Get help

- **Bug?** [Open an issue](https://github.com/downbadapp/community/issues/new?template=bug_report.md) — screenshots and repro steps help a ton.
- **Feature idea?** Start a [Feature Request](https://github.com/downbadapp/community/discussions/categories/feature-requests) thread.
- **Question?** Check [Q&A](https://github.com/downbadapp/community/discussions/categories/q-a) first, then ask away.
- **Updates?** Watch [Announcements](https://github.com/downbadapp/community/discussions/categories/announcements).

## What is DownBad?

[DownBad](https://downbad.app) is uptime monitoring for small teams, but all are welcome. $50/year gets you up to 100 monitors with Domain Bundle monitoring — drop in a domain and it auto-configures URL, SSL, DNS, and WHOIS checks. No fuss. You can still configure everything manually too.

## Ground rules

- Be kind.
- Search before posting.
- One issue per thread.
- Never share API keys, passwords, or account details publicly — we'll move somewhere if needed.

We're a small team. We see everything and aim to respond within a couple business days.
