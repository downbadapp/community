# DownBad Community

The place for support, bugs, feature requests, and general discussion. This is the best way to reach us.

## Get help

- **Bug or something not working?** [Open an issue](https://github.com/downbadapp/community/issues/new/choose). Screenshots and repro steps help a ton.
- **Feature idea?** Start a [Feature Request](https://github.com/downbadapp/community/discussions/categories/feature-requests) thread.
- **Question?** Check the [docs](https://downbad.app/docs/) and [Q&A](https://github.com/downbadapp/community/discussions/categories/q-a) first, then ask away.
- **Updates?** Watch [Announcements](https://github.com/downbadapp/community/discussions/categories/announcements). Every release in the [changelog](https://downbad.app/changelog) is posted there.

## What is DownBad?

[DownBad](https://downbad.app) watches everything that can go wrong with a domain in one place, and tells you in plain English when something does. Drop in a domain and it finds the website, SSL certificate, DNS records, and registration to watch, and flags certificate and domain expiry before they lapse. You can also set up website and port checks by hand.

It's built for people who run their own sites without a dedicated ops team: indie developers, solo founders, and small teams. There's a free plan, and you can run a one-off health check on any domain from the home page without an account. See [downbad.app](https://downbad.app) for plans and pricing.

## Ground rules

- Be kind.
- Search before posting.
- One issue per thread.
- Never post API keys, passwords, or account details. Open the issue without them, and we'll follow up privately if we need more.

We're a small team. We see everything and aim to respond within a couple business days.
